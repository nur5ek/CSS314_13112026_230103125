### Evidence-based interpretation
- The minimum median in the p=10 stride sweep is at stride=2 (16 B), 816.03 ms; stride=8 (64 B) takes 861.85 ms. There is **no measured sharp latency drop at the expected 64-byte boundary**. This experiment therefore does not empirically identify the coherence-line width, despite a nominal architectural value of 64 B.
- At 10 processes, stride=16 takes 854.91 ms versus 843.63 ms at stride=1 (+1.34% change, i.e. slightly slower rather than faster). Noise, OS scheduling, hybrid P/E-core placement, and Python interpreter overhead may mask cache-coherence costs. This is a hypothesis, not a demonstrated cause.
- For stride=1, e(p) runs 2: 0.152, 4: 0.145, 8: 0.292, 16: 0.213. The series is non-monotonic, so a steady rise in false-sharing penalty cannot be claimed from these data.
- For stride=16, e(p) runs 2: 0.173, 4: 0.140, 8: 0.187, 16: 0.240. The series is non-monotonic, so a steady rise in false-sharing penalty cannot be claimed from these data.
- **Methodological limitation:** each worker computes the accumulator in Python and writes it into shared memory in its inner loop. The benchmark also includes process creation and joining. These substantial costs and thread placement are not isolated from cache-coherence effects. A stronger conclusion would require CPU affinity, more controlled trials, and a lower-overhead native kernel.

## Phase 4 — Skewed scheduling and load imbalance

N=12,000 work items, p=10 workers. K(i)=1+floor((i/60)²) operations per item. For each scheduling method, λ=max(worker active time) / mean(worker active time). A value of 1 indicates perfect active-time balance.

| Strategy | Chunk C | Wall time (ms) | λ | Fastest worker (ms) | Slowest worker (ms) |
|---|---|---|---|---|---|
| block | — | 13347.12 | 2.7748 | 28.01 | 13098.45 |
| cyclic | — | 5284.88 | 1.0294 | 4685.61 | 5015.47 |
| dynamic | 1 | 4953.62 | 1.0124 | 4591.91 | 4709.12 |
| dynamic | 4 | 5086.80 | 1.0115 | 4776.66 | 4902.38 |
| dynamic | 16 | 5222.43 | 1.0215 | 4863.41 | 5066.52 |
| dynamic | 64 | 5456.18 | 1.0368 | 4813.83 | 5232.40 |
| dynamic | 256 | 5657.86 | 1.1323 | 3948.99 | 5349.77 |
| dynamic | 1024 | 6841.21 | 1.8405 | 658.72 | 6555.63 |

### Scheduling trade-off
- **Static contiguous block** yields large imbalance (λ=2.7748) because work items near the end of the array are much heavier. Its active worker times range from 28.01 to 13098.45 ms.
- **Cyclic static scheduling** interleaves light and heavy items and reduces λ to 1.0294, wall time 5284.88 ms.
- **Fastest dynamic scheduling:** C*=1, with wall time **4953.62 ms** and λ=1.0124. Compared with the contiguous block schedule it is **2.694× faster**, reducing wall time by **62.89%**.
- At C=1, frequent claims maximize shared-counter lock traffic but offer fine-grained balancing; its measured λ is 1.0124. At C=1024, fewer claims reduce locking overhead but coarse chunks leave skewed tails; λ rises to 1.8405 and wall time to 6841.21 ms. The direct contribution of lock contention was not instrumented independently.
- Best λ was at C=4 (1.0115), while best **elapsed time** was at C=1; these need not coincide.

### harness.py

```python
from dataclasses import dataclass
import multiprocessing as mp
import time
from statistics import median

@dataclass
class BenchStats:
    min_ms: float
    median_ms: float
    iqr_ms: float
    max_ms: float

def fnv1a_hash(s: str) -> int:
    h = 14695981039346656037
    for b in s.encode('utf-8'):
        h = ((h ^ b) * 1099511628211) & 0xFFFFFFFFFFFFFFFF
    return h

def run_benchmark(fn, warmup_runs=3, timed_runs=9):
    for _ in range(warmup_runs): fn()
    samples=[]
    for _ in range(timed_runs):
        start=time.perf_counter_ns(); fn()
        samples.append((time.perf_counter_ns()-start)/1e6)
    samples.sort(); n=len(samples)
    return BenchStats(samples[0],median(samples),samples[(3*n)//4]-samples[n//4],samples[-1])

def emit_verify_tag(task_id, student_seed, primary_metric, secondary_metric):
    hw=mp.cpu_count()
    payload=f'{task_id}|{student_seed}|{hw}|{primary_metric:.4f}|{secondary_metric:.4f}'
    return f'VERIFY_HASH[{task_id}]: {fnv1a_hash(payload):016X} (P_log={hw})'
```

### task3b_gemm.py
```python
import argparse, json, multiprocessing as mp, time
from multiprocessing import shared_memory
from statistics import median
from harness import emit_verify_tag
TILES=[4,8,12,16,24,32,48,64,96,128]

def gemm_worker(names,n,lo,hi,variant,bs):
    blocks=[shared_memory.SharedMemory(name=x) for x in names]
    a,b,c=[sh.buf.cast('d') for sh in blocks]
    try:
        if variant==1:
            for i in range(lo,hi):
                for j in range(n):
                    val=0.0
                    for k in range(n):val+=a[i*n+k]*b[k*n+j]
                    c[i*n+j]=val
        elif variant==2:
            for i in range(lo,hi):
                for k in range(n):
                    aik=a[i*n+k]
                    for j in range(n):c[i*n+j]+=aik*b[k*n+j]
        else:
            for ii in range(lo,hi,bs):
                for jj in range(0,n,bs):
                    for kk in range(0,n,bs):
                        for i in range(ii,min(ii+bs,hi)):
                            for k in range(kk,min(kk+bs,n)):
                                aik=a[i*n+k]
                                for j in range(jj,min(jj+bs,n)):
                                    c[i*n+j]+=aik*b[k*n+j]
    finally:
        del a,b,c
        for sh in blocks:sh.close()

def main():
    ap=argparse.ArgumentParser();ap.add_argument('--id',type=int,required=True);ap.add_argument('--physical',type=int,required=True);ap.add_argument('--quick',action='store_true');a=ap.parse_args()
    n=48 if a.quick else 384
    blocks=[shared_memory.SharedMemory(create=True,size=n*n*8) for _ in range(3)]
    try:
        av,bv,cv=[s.buf.cast('d') for s in blocks]
        for i in range(n*n):av[i]=(i%17-8)/17;bv[i]=(i%13-6)/13
        def run(variant,bs):
            for i in range(n*n):cv[i]=0.0
            names=[s.name for s in blocks]
            st=time.perf_counter_ns()
            ps=[mp.Process(target=gemm_worker,args=(names,n,n*t//a.physical,n*(t+1)//a.physical,variant,bs)) for t in range(a.physical)]
            for p in ps:p.start()
            for p in ps:p.join()
            if any(p.exitcode for p in ps):raise RuntimeError('GEMM worker failed')
            elapsed=(time.perf_counter_ns()-st)/1e6
            return elapsed
        rows=[]
        for variant,bs in [(1,0),(2,0)]+[(3,b) for b in TILES]:
            samples=[run(variant,bs) for _ in range(1 if a.quick else 3)]
            med=median(samples)
            row={'variant':variant,'bs':bs,'median_ms':med,'gflops':2*n**3/(med*1e6),'tile_bytes':3*bs*bs*8 if bs else None}
            rows.append(row);print(row,flush=True)
            if variant==2:reference=list(cv)
            if variant==3 and bs==TILES[0]:diff=max(abs(cv[i]-reference[i]) for i in range(n*n))
        best=max(rows[2:],key=lambda r:r['gflops'])
        out={'student_id':a.id,'quick':a.quick,'n':n,'rows':rows,'max_error_vs_variant2':diff,'best_bs':best['bs'],'verify':emit_verify_tag('PHASE3',a.id,rows[0]['gflops'],best['gflops'])}
        open('phase3b.json','w').write(json.dumps(out,indent=2));print(out['verify'])
        del av,bv,cv
    finally:
        for sh in blocks:sh.close();sh.unlink()
if __name__=='__main__':mp.freeze_support();main()
```

### task4_scheduling.py
```python
import argparse, json, math, multiprocessing as mp, time
from statistics import median
from harness import emit_verify_tag
CHUNKS=[1,4,16,64,256,1024]

def do_item(i,quick):
    repeats=1+(i*i)//3600
    if quick:repeats=max(1,repeats//1000)
    v=0.0
    for k in range(repeats):v+=math.sin(k*0.0001)*math.cos(k*0.0002)+math.sqrt(k+1)*0.00000001
    return v

def worker(t,p,n,strategy,chunk,queue_index,lock,active,quick):
    start=time.perf_counter_ns();total=0.0
    if strategy=='block':
        for i in range(t*n//p,(t+1)*n//p):total+=do_item(i,quick)
    elif strategy=='cyclic':
        for i in range(t,n,p):total+=do_item(i,quick)
    else:
        while True:
            with lock:
                start_idx=queue_index.value;queue_index.value+=chunk
            if start_idx>=n:break
            for i in range(start_idx,min(n,start_idx+chunk)):total+=do_item(i,quick)
    active[t]=(time.perf_counter_ns()-start)/1e6

def main():
    ap=argparse.ArgumentParser();ap.add_argument('--id',type=int,required=True);ap.add_argument('--physical',type=int,required=True);ap.add_argument('--quick',action='store_true');a=ap.parse_args()
    n=1200 if a.quick else 12000;rows=[]
    for strategy,chunk in [('block',0),('cyclic',0)]+[('dynamic',c) for c in CHUNKS]:
        counter=mp.Value('i',0);lock=mp.Lock();times=mp.Array('d',a.physical)
        st=time.perf_counter_ns()
        ps=[mp.Process(target=worker,args=(t,a.physical,n,strategy,chunk,counter,lock,times,a.quick)) for t in range(a.physical)]
        for p in ps:p.start()
        for p in ps:p.join()
        if any(p.exitcode for p in ps):raise RuntimeError('worker failure')
        elapsed=(time.perf_counter_ns()-st)/1e6
        vals=list(times);lam=max(vals)/(sum(vals)/len(vals)) if sum(vals)>0 else float('nan')
        row={'strategy':strategy,'chunk':chunk,'wall_ms':elapsed,'lambda':lam,'worker_ms':vals}
        rows.append(row);print(row,flush=True)
    best=min(rows[2:],key=lambda x:x['wall_ms'])
    out={'student_id':a.id,'quick':a.quick,'n':n,'rows':rows,'best_chunk':best['chunk'],'verify':emit_verify_tag('PHASE4',a.id,rows[0]['wall_ms'],best['wall_ms'])}
    open('phase4.json','w').write(json.dumps(out,indent=2));print(out['verify'])
if __name__=='__main__':mp.freeze_support();main()
```
